# HSC Science Hub 🎓

**HSC Science Hub** is a frontend-based educational website designed to help HSC Science students in Bangladesh study in a more organized and effective way.

The platform brings subjects, chapters, learning resources, videos, practice questions, tests and study progress into one simple interface.

## 🌐 Live Website

**HSC Science Hub:**
https://tanjimapinke.github.io/HSC-Science-Hub/

## 🎯 Project Goal

The main goal of HSC Science Hub is to create a simple and organized digital study environment for HSC Science students.

Instead of searching for different study materials across multiple places, students can use one platform to:

**Learn → Practice → Test → Improve**

---

## 🚀 Running the Project Locally

No server or backend is required.

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/HSC-Science-Hub.git
```

### 2. Open the project

Open the project folder in **VS Code**.

### 3. Run the website

Open `index.html` in a browser.

You can also use the **Live Server** extension in VS Code for easier development.

---

## 🌍 Deployment

This project is a static frontend website and can be hosted using **GitHub Pages**.

Deployment:

```text
GitHub Repository
       ↓
   GitHub Pages
       ↓
Live Website
```
